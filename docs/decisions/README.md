## Proposing and superseding a decision

A decision is proposed in a pull request that adds a section `## ADR-0NN: <title>` with the next free number to the scope file it belongs to, with `Status: Proposed, <date>`, and a row in the index above. Review happens in the pull request; on merge the status becomes `Accepted`. A decision is never rewritten after acceptance: a later record supersedes it, the superseded record gets a note naming its successor in its status line, and the successor states what it replaces.

## Numbering

ADR numbers are never reused or renumbered, so the sequence has gaps.
