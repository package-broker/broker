Planned for 2.0: projects, roles, groups, personal access tokens and service tokens.

On the current `main` there is no route or command to create projects, assign roles or issue tokens. The only role assignment is the `organization_admin` role that `pb admin bootstrap` and `pb admin reset-local` give. Sign-in is described in [Authentication and sessions](authentication.md).
