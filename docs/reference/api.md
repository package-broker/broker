Planned for 2.0: the HTTP API for projects, tokens and audit, and its OpenAPI document.

The API routes served today are the authentication, session and health routes listed in [Authentication and sessions](authentication.md#routes). When the web interface assets are deployed, the broker also serves the placeholder interface under `/_pb/ui` (`/_pb/ui`, `/_pb/ui/manifest.json` and `/_pb/ui/assets/{file}`).
