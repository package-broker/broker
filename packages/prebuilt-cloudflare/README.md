# @package-broker/dist-cloudflare

This package contains the prebuilt Package Broker Cloudflare Worker in `cloudflare/` and release metadata in `prebuilt.json`. The release process supplies these payload files; they are absent from the source checkout.

See the [quickstart](https://github.com/package-broker/broker/blob/main/docs/getting-started/quickstart-cloudflare.md) for setup instructions.
